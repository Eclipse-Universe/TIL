# Git & GitHub 기초

## 오늘 배운 것
- Working Directory, Staging Area, Local Repository 개념
- clone → add → commit → push 기본 사이클
- 브랜치 생성, merge, 삭제
- Conventional Commits
- Fork & Pull Request 흐름

## 주요 명령어
| 명령어 | 설명 |
|--------|------|
| git clone | 원격 저장소 가져오기 |
| git add | staging에 올리기 |
| git commit | 로컬에 저장 |
| git push | GitHub에 업로드 |
| git switch -c | 브랜치 생성 & 이동 |
| git merge | 브랜치 합치기 |
