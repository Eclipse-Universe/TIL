# 🚀 2026.04.01 TIL: 문서 분류 프로젝트 성능 한계 돌파 및 메가 앙상블 구축

## 1. 모델 아키텍처 특성 이해 및 앙상블 코드 디버깅
* CNN(ConvNeXt)과 ViT(SwinV2)의 구조적 차이로 인해 `timm` 모델 로드 시 발생하는 파라미터(`img_size`) 충돌 에러 확인 및 디버깅 수행
* 아키텍처 이름에 따른 조건문 분기 처리를 통해 안정적인 가중치 로드 파이프라인 완성
* 모델별 OOF 점수를 기반으로 최적화된 비중을 곱하는 소프트 보팅(Soft Voting) 개념 실전 적용

## 2. 하이브리드 모델(MaxViT) 도입 및 VRAM 메모리 최적화
* CNN의 국소적 특징 추출과 Transformer의 전역적 문맥 파악 능력을 결합한 하이브리드 모델 `maxvit_base_tf_512.in1k` 도입
* 512px 고해상도 이미지 학습 시 발생하는 그래픽카드 OOM(Out of Memory) 문제 직면
* PyTorch의 `Gradient Checkpointing` 기술을 활성화하여 연산 시간을 일부 희생하고 VRAM 사용량을 극적으로 단축하여 Batch Size 8 유지 성공
* 단일 모델 기준 OOF Macro F1 Score 0.9502 달성으로 로컬 최고점 경신

## 3. OOF와 LB의 디커플링 현상 분석 및 해결 전략
* MaxViT의 OOF 점수는 0.9502로 역대 최고를 기록했으나, 리더보드(LB) 점수는 0.9376으로 하락하는 디커플링(과적합) 현상 확인
* 단일 모델이 학습 데이터의 지엽적 패턴에 과하게 매몰될 때 일반화 성능이 무너진다는 딥러닝의 본질적 한계 체감
* 일반화 방어력이 뛰어난 v3.0과 특정 패턴 인식에 강한 v4.0의 확률값을 합치는 메가 앙상블 전략 수립
* ConvNeXt(0.35) + SwinV2(0.25) + MaxViT(0.40) 비율의 최종 Soft Voting 파이프라인 구축

## 4. 도메인 특화 증강(TTA) 최적화
* 문서 분류라는 도메인 특성을 고려하여 텍스트 방향과 레이아웃을 훼손하는 상하 반전 및 90도 회전 증강 제거
* 좌우 반전, 밝기 조절, 미세 확대 등 문서 본연의 특징을 살리는 안전한 4배수 TTA로 추론 안정성 극대화
