## 🛠️ 트러블슈팅 (Troubleshooting)
1. **W&B Circular Import 에러**
   - **증상:** `AttributeError: module 'wandb' has no attribute 'init'`
   - **원인:** 테스트용 스크립트 파일명을 라이브러리 이름과 동일한 `wandb.py`로 설정하여 순환 참조 발생.
   - **해결:** 파일명을 `test_wandb.py`로 변경하여 해결.

2. **Swin Transformer V2 Patch 규격 에러**
   - **증상:** `RuntimeError: shape is invalid for input of size...`
   - **원인:** `window12` 규격의 Swin 모델은 이미지를 12칸짜리 바둑판으로 쪼개야 하는데, 512px(압축 후 66px 등)이 12로 나누어떨어지지 않음.
   - **해결:** 512px 사이즈에 수학적으로 완벽하게 떨어지는 `swinv2_base_window16_256` (16칸 바둑판) 모델로 교체하여 해결.

3. **추론 시 메모리 초과(OOM) 및 예측값 오염**
   - **증상:** 앙상블 과정에서 예측값이 전부 클래스 '0'으로 쏠리는 현상.
   - **원인:** 하나의 모델 학습이 완료되지 않아 파일이 없는 상태에서 빈 배열의 평균을 구하려다 `NaN`이 발생했고, 이것이 전체 예측을 오염시킴.
   - **해결:** 모델 가중치 파일의 존재 여부를 체크하고, 512px 추론 시 `batch_size=8`로 고정하여 OOM 방지.

## 🚀 파이프라인 고도화 기록
- **v2.1 (안정화):**
  - 강제 Resize로 인한 이미지 찌그러짐을 방지하기 위해 `LongestMaxSize` + 흰색 배경 `PadIfNeeded` 적용.
  - 소수 클래스에 대한 과적합(Double-dipping)을 막기 위해 Loss 함수의 가중치를 제거하고 `WeightedRandomSampler`만 단독 유지.
  - TTA 회전 시 발생하는 노이즈를 `border_mode=0`으로 차단.
- **v2.2 (불균형 타격):**
  - **LDAM Loss + DRW(Deferred Re-Weighting):** 학습 후반부(80% 시점)에 소수 클래스 가중치를 부여하여 마진을 넓히는 기법 적용. ConvNeXt-Base 기준 OOF F1 0.9533 달성. (단, LB 스코어는 0.9300으로 하락하여 과적합 확인)
- **v3.0 (관점의 확장):**
  - LDAM을 제거하고 해상도를 **384px ➔ 512px**로 대폭 상향.
  - 픽셀의 형태를 보는 CNN(ConvNeXt)과 전체 문맥을 보는 Transformer(SwinV2)의 **영혼의 듀오 앙상블** 세팅.
  - VRAM 한계를 극복하기 위해 `batch_size=8`과 **Gradient Accumulation(누적 스텝=2)**을 결합하여 실질적 배치 사이즈 16의 효과 구현.
